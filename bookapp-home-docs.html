نظرة عامة

الهوم عبارة عن مصفوفة كومبوننتس مرتبة. الأب يلفّ على المصفوفة ويرسم كل عنصر حسب نوعه بنفس الترتيب — مفيش هيكل ثابت.

  • كل عنصر شكله: { "component": "النوع", "data": { ... } }.
  • الأنواع الحالية 5: announcement · banners · component_ids · products_section · call_to_action.
  • نفس النوع ممكن يتكرر أكتر من مرة (مثلًا 3 سلايدرز منتجات ورا بعض بإعدادات مختلفة).
  • كل الداتا بترجع جاهزة (resolved): البنرات بصورها، التصنيفات بأساميها وصورها وعدد كتبها، والمنتجات كروت كاملة — الهوم بترسم بطلب واحد من غير طلبات إضافية.
  • الترتيب والإضافة والحذف والتفعيل كله من ووردبريس → BookApp → Home Builder (شوف قسم الإدارة تحت).
⚠️ الهوم القديمة GET /wp-json/bookapp/v1/home (هيكل ثابت: hero / highlights / sections...) لسه شغالة لكنها هتتشال بعد اعتماد النسخة دي. متبنيش عليها أي شاشة جديدة — ابني على bookapp/v2/home بس.

الطلب

GET https://books.ay7aaga.com/wp-json/bookapp/v2/home عام — من غير توكن
باراميتر / هيدرالقيمةملاحظات
?lang=ar | enلغة النصوص (العناوين، الأزرار، الإعلان...). لو مش مبعوتة بيتقرأ Accept-Language، والافتراضي عربي. لو الترجمة الإنجليزية فاضية بيرجع النص العربي بدلها.

قواعد للأب

  • الترتيب ملزم: ارسم الكومبوننتس بنفس ترتيب المصفوفة.
  • الكومبوننت المعطّل من الداشبورد مش بيرجع أصلًا — مفيش حقل enabled في الرد.
  • «مخفي من التطبيق»: المنتجات والتصنيفات/الوسوم/المؤلفين/دور النشر المتعلّم عليها «مخفي» في ووردبريس بتتشال من الرد تلقائيًا — سيكشن منتجات مرتبط بتيرم مخفي بيختفي كله.
  • نوع مش معروف؟ تجاهله. ممكن نضيف أنواع جديدة في المستقبل — الأب اللي قديم يعدّيها من غير ما يقع (forward compatibility).
  • مصفوفة فاضية (items / products / banners) = متعرضش السيكشن ده أصلًا.
  • الـ IDs في الأكشنز بترجع نص ("198")، والـ ids جوه component_ids و banner_ids بترجع أرقام.

أنواع الكومبوننتس الخمسة

كل الأمثلة اللي تحت دي ردود حقيقية من الموقع (مقصّرة في المصفوفات الطويلة بس).

announcement شريط إعلان أعلى الشاشة
حقلالنوعالوصف
textنصنص الإعلان حسب اللغة
actionTypeنصنوع الأكشن عند الضغط — شوف قسم الأكشنز. فاضي = الشريط مش قابل للضغط
actionTargetنصالـ ID الهدف، أو الرابط الكامل لو actionType=url

مثال

{
  "component": "announcement",
  "data": {
    "text": "يمكنك الدفع أونلاين من خلال فيزا - محفظة - ميزة كما يمكنك التقسيط من خلال البنك الأهلي 6 و 12 شهر ومن خلال فاليو وسهولة",
    "actionType": "category",
    "actionTarget": "198"
  }
}
banners سلايدر بنرات (صور بعناوين وأكشن)

البنرات بتتدار من الداشبورد كـ Custom Post Type (ووردبريس → BookApp → البنرات): لكل بنر عنوان ووصف عربي/إنجليزي + صورة + أكشن. الكومبوننت بيرجع البنرات المنشورة بس.

حقلالنوعالوصف
banner_idsأرقام []الإعداد المكتوب في الداشبورد. البنرات بترجع بنفس ترتيبه. لو فاضي → كل البنرات المنشورة (الأحدث أولًا)
banners[].idرقمID البنر
banners[].title / subtitleنصحسب اللغة — ممكن subtitle يبقى فاضي
banners[].imageUrlنصرابط الصورة (الحجم الكامل). ممكن يبقى فاضي لو البنر من غير صورة
banners[].actionType / actionTargetنصأكشن الضغط على البنر — فاضي = عرض بس من غير ضغط

component_ids كروت عناصر بالـ IDs — تصنيفات / مؤلفين / دور نشر / وسوم / منتجات مختارة

سيكشن عام: الأدمن بيختار نوع العناصر (actionType) ويكتب الـ IDs، والـ API بيرجعها كروت جاهزة في items. شكل العنصر بيختلف حسب النوع:

actionTypeشكل العنصر في items
category{ id, name, count, image, parent }
tag{ id, name, count, image }
author{ id, name, count, image, bio? }
publisher{ id, name, count, image }
productكروت منتجات كاملة — نفس كارت المنتج (سيكشن «منتجات مختارة يدويًا»)

قواعد

  • count = عدد الكتب جوه التصنيف / للمؤلف / للدار.
  • image: صورة الترم لو متسجلة في ووكومرس، وإلا default_image بتاعة السيكشن، وإلا null. مفيش صورة افتراضية عامة للمؤلف أو الدار.
  • لو actionType=category والأدمن ساب الـ ids فاضية → بيرجع كل التصنيفات الرئيسية (parent categories) تلقائيًا.
  • bio (للمؤلف بس): وصف الترم — HTML وممكن يكون طويل جدًا (مقالات SEO). لو هتعرضه اعمل strip للـ HTML وقصّه (سطرين مثلًا)، أو تجاهله خالص. مش بيرجع لو فاضي.
  • parent (للتصنيف بس): 0 يعني تصنيف رئيسي.

products_section سلايدر منتجات — من مصدر + ترتيب
حقلالنوعالوصف
title / button_textنصعنوان السيكشن ونص زرار «عرض الكل» حسب اللغة
sort_byنصترتيب المنتجات — القيم في الجدول تحت
action_typeنصمصدر المنتجات + هدف زرار «عرض الكل»
action_targetنصID الترم / المنتج — فاضي مع all / sale / featured
limitرقمعدد المنتجات (1–24، الافتراضي 10)
products[]كروت منتجات كاملة — شوف كارت المنتج. متوفرة في المخزون بس

قيم action_type (المصدر)

القيمةالمنتجات اللي بترجع
allكل المتجر (بالترتيب المختار)
saleالمنتجات المخفّضة
featuredالمنتجات المميزة (⭐ في ووكومرس)
category / tag / author / publisherمنتجات الترم اللي في action_target
productمنتج واحد بعينه (الـ ID في action_target)

قيم sort_by

القيمةالترتيب
newestالأحدث أولًا (الافتراضي)
oldestالأقدم أولًا
best_sellingالأكثر مبيعًا
price_low_to_highالسعر تصاعدي
price_high_to_lowالسعر تنازلي

}

زرار «عرض الكل»: افتح شاشة اللستة بنفس action_type / action_target (مثلًا sale → شاشة كل المخفّض، category:198 → شاشة التصنيف 198).

call_to_action بلوك دعوة لإجراء — عنوان + وصف + زرار
حقلالنوعالوصف
title / subtitleنصحسب اللغة
button_textنصنص الزرار
actionType / actionTargetنصأكشن الزرار — شوف قسم الأكشنز

  "data": {

    "button_text": "عرض الكل",
    "actionType": "category",
    "actionTarget": "198"
  }
}

الأكشنز — actionType / actionTarget

نفس المنطق في كل الكومبوننتس: لما المستخدم يدوس (على البنر / الإعلان / زرار الـ CTA / كارت عنصر)، الأب يفتح الشاشة دي:

actionTypeactionTargetالأب يفتح
categoryID تصنيفشاشة منتجات التصنيف (فلتر product_cat)
tagID وسمشاشة منتجات الوسم (فلتر product_tag)
productID منتجصفحة المنتج
authorID مؤلفشاشة منتجات المؤلف (فلتر pa_writer)
publisherID دار نشرشاشة منتجات الدار (فلتر pa_publisher)
urlرابط كامل https://...افتح الرابط في المتصفح / WebView — متاح في الإعلان والبنر والـ CTA بس
فاضي ""—مفيش أكشن — العنصر للعرض بس
ملاحظات: الـ actionTarget بيرجع نص. لو النوع ID ("198") حوّله رقم عندك. لو actionType=url خليه رابط وافتحه زي ما هو. لو actionType ليه قيمة وactionTarget فاضي، اعتبره «مفيش أكشن» برضه. في component_ids الضغط على أي كارت بيفتح نفس نوع الشاشة بالـ id بتاع الكارت نفسه، وفي products_section القيم الإضافية (all / sale / featured) بتفتح شاشة اللستة بالفلتر المقابل.

الإدارة من الداشبورد (للأدمن)

الصفحةبتعمل إيه
ووردبريس → BookApp → Home Builderترتيب الهوم: إضافة كومبوننت من الدروب داون، سحب من المقبض لإعادة الترتيب، تشيك بوكس «ظاهر» للتفعيل/التعطيل، زرار «مسح»، وكل التعديلات بتتثبت بزرار «حفظ الهوم الجديدة». فوق الصفحة لستة بالبنرات المتاحة وأرقامها
ووردبريس → BookApp → البنراتإضافة/تعديل البنرات: العنوان (عربي) + العنوان الإنجليزي + الوصف بالعربي والإنجليزي + صورة البنر (Featured Image) + actionType/actionTarget. الـ ID ظاهر في عمود في الجدول وفي صندوق جانبي جوه صفحة التعديل. البنر لازم يكون منشور عشان يظهر
بعد أي تعديل لو الرد في الأب لسه قديم: امسح الكاش (WP-Optimize) وجرّب تاني. صفحة إعدادات BookApp القديمة لسه موجودة لكنها بتتحكم في الهوم القديمة بس.
