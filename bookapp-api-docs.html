الهيدرز والقواعد

ابعت JSON دائمًا. اللغة الافتراضية عربي.

السلة والكتالوج العام على Store API الجاهز من ووكومرس. الحساب / الهوم / المفضلة / المقارنة / الطلبات / الدفع المغلف على bookapp/v1.
«العرض في التطبيق» — كل منتج / تصنيف / وسم / مؤلف / دار نشر ليه فلاج بيتحكم فيه من ووردبريس (صفحة المنتج أو صفحة التيرم — الافتراضي: ظاهر). اللي متعلّم عليه «مخفي» بيختفي من كل API التطبيق (bookapp/v1 و v2 و Store API): القوائم والبحث والهوم والمفضلة والمقارنة، وطلب المنتج المفرد بيرجع 404 (bookapp_product_missing في bookapp أو 404 من Store API). إخفاء تصنيف رئيسي بيخفي التصنيفات الفرعية اللي تحته تلقائيًا، والفلاج بيتزامن بين ترجمات العربي والإنجليزي. الاستثناءات: المنتج المخفي بيفضل ظاهر جوه تفاصيل الطلبات القديمة، وأسماء التصنيفات/المؤلفين بتفضل ظاهرة جوه categories و attributes بتوع كارت منتج ظاهر. إخفاء تصنيف مش بيخفي كتبه (الكتاب بيتخفي من فلاج المنتج نفسه). الموقع الإلكتروني مش بيتأثر إطلاقًا.
هيدرمتى
Content-Type: application/jsonأي POST / PATCH / PUT

X-BookApp-App: 1عند التشيك أوت عشان رجوع EasyKash يروح للأب
X-BookApp-Platform: android أو iosمع bootstrap / settings عشان الـ API يحسب app.status (تحديث اختياري أو إجباري)

Cart-Tokenسلة الزائر من أول GET https://books.ay7aaga.com/wp-json/wc/store/v1/cart

GET https://books.ay7aaga.com/wp-json/bookapp/v2/home عام الهوم الجديدة

الهوم الجديدة — كومبوننتس. الرد components: مصفوفة مرتبة، كل عنصر { component, data }. الترتيب والإضافة والحذف والتفعيل كله من ووردبريس → BookApp → Home Builder. الأب يرسم الشاشة بنفس ترتيب المصفوفة — ممكن يتكرر نفس النوع أكتر من مرة (مثلًا 3 سلايدرز منتجات). كل الداتا بترجع جاهزة (resolved) — مفيش داعي لطلبات إضافية لرسم الهوم. عناصر «مخفي من التطبيق» بتتشال تلقائيًا: products_section المرتبط بتيرم مخفي بيختفي كله، والتيرمز/المنتجات المخفية بتتشال من component_ids.items ومن products.

componentالداتا اللي بترجع في data
announcementtext حسب اللغة + actionType / actionTarget
bannersbanner_ids (الإعداد) + banners: بنرات جاهزة {id, title, subtitle, imageUrl, actionType, actionTarget}. البنرات بتتدار من ووردبريس → BookApp → البنرات (Custom Post Type — العنوان والوصف عربي/إنجليزي + صورة + أكشن). بترجع المنشور بس وبنفس ترتيب الـ IDs. لو banner_ids فاضية → كل البنرات المنشورة (الأحدث أولًا)
component_idsكروت بالـ IDs: title, button_text, actionType (category / tag / product / author / publisher), ids, default_image, items. للتصنيفات: {id, name, count, image, parent}. للمؤلفين: {id, name, count, image, bio?}. لدور النشر والوسوم: {id, name, count, image}. لو actionType=product: items = كروت منتجات كاملة. لو actionType=category و ids فاضية → كل التصنيفات الرئيسية (parent). الصورة: صورة الترم لو موجودة، وإلا default_image بتاعة السيكشن، وإلا null
products_sectionسلايدر منتجات: title, button_text, sort_by, action_type, action_target, limit (1–24), products = كروت منتجات كاملة (نفس شكل كارت المنتج + in_wishlist / in_compare حسب X-BookApp-Guest أو التوكن). المنتجات متوفرة في المخزون بس
call_to_actiontitle, subtitle, button_text, actionType, actionTarget
حقلالقيم
products_section.action_typeall كل المنتجات · sale المخفّض · featured المميز · category / tag / author / publisher (مع action_target = ID الترم) · product (منتج واحد بالـ ID)
products_section.sort_bynewest · oldest · best_selling · price_low_to_high · price_high_to_low
actionType (أكشن الضغط)category · tag · product · author · publisher · url · فاضي = بدون أكشن. actionTarget = الـ ID كنص، أو الرابط الكامل (https://...) لو actionType=url
